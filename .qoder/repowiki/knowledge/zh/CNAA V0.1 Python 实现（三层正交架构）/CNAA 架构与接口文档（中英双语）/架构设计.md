本模块为纯文档目录，按语言分置 en/ 与 zh/ 两个平行子目录，每个子目录包含三份核心文档：
- architecture.md：架构总览文档，定义三层正交架构（接口契约层、运行时层、生命周期层）、设计原则（哑服务、接口优先、可插拔、本地优先、强定制性）、系统边界与部署拓扑。
- api-reference-v0.1.md：API 参考规范，定义 Memory、TaskCheckpoint、State、Preference、Environment、InstantMemory 等数据模型，以及 store/get/list/tag/delete 等交互接口和 MCP 工具清单（cnaa_store_memory、cnaa_get_memory 等）。
- architecture-vision-v0.1.md：架构愿景文档。
两份语言版本内容一一对应，形成完整的中英双语技术文档体系，作为 Python 参考实现的契约依据。
