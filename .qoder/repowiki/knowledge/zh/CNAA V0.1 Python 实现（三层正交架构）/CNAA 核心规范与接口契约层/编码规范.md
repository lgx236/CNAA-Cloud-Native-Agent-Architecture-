- 数据模型统一使用 @dataclass 定义并在 __post_init__ 中为 timestamp/updated_at 字段设置默认值 datetime.now()。
- JSON Schema 集中定义在 schemas.py 中，每个 schema 常量包含 type、properties、required 三要素，并通过 get_all_schemas/get_request_schemas/get_response_schemas 三类注册函数暴露。
- 抽象接口统一继承自 abc.ABC 并使用 @abstractmethod 装饰方法，返回值遵循统一的 {"status": "ok"} 字典格式。
- 插件体系通过 ABC 接口 + 默认实现 + LifecyclePlugins 注册表的模式设计，允许外部包替换 MemoryLifecyclePlugin/RetrievalPlugin/StateEvolutionPlugin。
- MCP 工具名称统一使用 cnaa_ 前缀命名（如 cnaa_store_memory），工具定义由 get_tool_definitions() 集中生成，inputSchema 引用 schemas.py 中的请求 Schema。
- __init__.py 显式 re-export 所有公共符号到包级命名空间，形成单一入口的 API 表面。
