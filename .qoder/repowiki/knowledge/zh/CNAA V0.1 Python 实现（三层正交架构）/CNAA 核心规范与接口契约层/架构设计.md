本模块采用三层正交架构：
- 数据模型层（models.py）：使用 dataclass 定义 Memory、State、Preference、Environment、InstantMemory、TaskCheckpoint 等核心实体，配合 MemoryType/MemoryStatus/StateCategory 枚举描述状态机。
- 接口契约层（schemas.py + interaction.py）：schemas.py 作为 JSON Schema 的唯一真相源（Single Source of Truth），提供 get_all_schemas/get_request_schemas/get_response_schemas 等注册器；interaction.py 通过 ABC 抽象类定义 MemoryInterface 和 StateInterface，明确本地-云端交互的 WHAT 而非 HOW。
- 生命周期与扩展层（lifecycle.py）：定义 MemoryLifecyclePlugin、RetrievalPlugin、StateEvolutionPlugin 三大插件接口及默认 TimeBasedLifecyclePlugin/DefaultStateEvolutionPlugin 实现，通过 LifecyclePlugins 注册表统一管理。
- MCP 工具层（tools.py）：以 schemas.py 中的请求 Schema 为输入参数定义所有 MCP 工具（cnaa_store_memory、cnaa_get_memory 等），提供 get_tool_definitions/get_tool_by_name/get_tool_names 查询 API。
- __init__.py 统一导出所有公共符号，声明版本 0.1.0，并强调 Cloud/ 与 local/ 是参考实现，本包即架构规范本身。依赖方向单向向下：tools → schemas → models；lifecycle 独立于 tools；interaction 仅依赖 models。
