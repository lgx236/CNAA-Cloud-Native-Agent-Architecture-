模块采用三层正交结构：
- 接口契约层 `agent.py` 中的 `LocalAgentInterface` 是对外唯一入口，聚合三个子组件并统一暴露 Memory/State/Preference/Environment 操作。
- 运行时层 `client/mcp_client.py` 的 `CNAA_MCPClient` 通过 `_call_tool` 统一转发到云端 MCP Server，工具名以 `cnaa_` 前缀命名（如 `cnaa_store_memory`），并通过 `set_mock_handler` 注入测试用的 mock server。
- 生命周期层 `memory/instant_memory.py` 的 `InstantMemoryManager` 维护进程内内存中的即时记忆，按 ACTIVE→CONDENSED→EVICTED 状态机管理短期摘要；`state/state_cache.py` 的 `StateCache` 基于 TTL 缓存 State/Preference/Environment，写操作后由 `LocalAgentInterface` 调用 `clear()` 失效。
依赖方向单向向下：`agent.py` → (`mcp_client`, `instant_memory`, `state_cache`)，各子包仅依赖 `cnaa.models` 数据模型，不互相耦合。
