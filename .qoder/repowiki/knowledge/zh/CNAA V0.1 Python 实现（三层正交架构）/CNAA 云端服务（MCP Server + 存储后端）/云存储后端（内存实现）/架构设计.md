本模块是存储抽象层的内存参考实现，采用接口-实现分离设计：
- `__init__.py` 统一暴露 `InMemoryMemoryStore` 和 `InMemoryStateStore` 两个类，作为包对外契约。
- `memory_store.py` 实现 `cnaa.interaction.MemoryInterface`，以 `(agent_id, memory_id)` 元组为键将 `Memory` 对象存入字典，支持按类型和标签过滤列出 `MemorySummary`。
- `state_store.py` 实现 `cnaa.interaction.StateInterface`，分别用三个字典维护 `State`、`Preference`、`Environment`，键分别为 `(agent_id, state_id)`、`(agent_id, preference_id)`、`agent_id`。
- 依赖方向单向指向 `cnaa.models`（数据模型）和 `cnaa.interaction`（接口定义），不反向依赖上层业务逻辑。
- 所有写操作返回统一的 `{"status": "ok"}` 字典，读操作返回模型对象或列表，测试辅助方法通过 `clear()`/`count_*()` 暴露内部状态。
