- 每个存储类都继承自对应的 `*Interface`（`MemoryInterface` / `StateInterface`），并以 `InMemory*Store` 命名约定标识内存实现。
- 数据存储统一使用嵌套字典结构，键为 `(agent_id, id)` 元组以实现多租户隔离，属性前缀加下划线表示私有字段。
- 所有写操作方法返回统一的 `{"status": "ok"}` 字典，读方法返回模型对象或 `None`，保持 API 一致性。
- 测试辅助方法（`clear`、`count`、`count_states` 等）独立于业务 CRUD 方法，便于单元测试时重置和断言内部状态。
- 文件头部包含三行 docstring 说明用途、数据来源和可替换性，明确标注该实现仅用于测试和开发。
