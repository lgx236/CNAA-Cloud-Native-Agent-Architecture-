- 所有工具处理函数统一以 `_handle_工具名` 命名并注册到 `_tool_handlers` 字典，由 `handle_tool_call` 统一分派
- 存储后端必须实现 `cnaa.interaction` 中定义的 `StateInterface` / `MemoryInterface` 抽象类，返回统一的 `{status: ...}` 字典格式
- 错误响应统一采用 `{"status": "error", "message": str(e)}` 或 `{"status": "not_found", ...}` 结构
- Python Agent 接口方法全部通过 `self.server.handle_tool_call(工具名, 参数)` 转发，不直接访问存储层
