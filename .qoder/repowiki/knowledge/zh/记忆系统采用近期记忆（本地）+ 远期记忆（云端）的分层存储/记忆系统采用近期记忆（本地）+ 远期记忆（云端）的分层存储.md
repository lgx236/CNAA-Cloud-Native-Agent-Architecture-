# 记忆系统采用近期记忆（本地）+ 远期记忆（云端）的分层存储

_来源：966265f → 90cf9d3 提交周期内记录的编码计划——内容为规划时意图，实现可能滞后或有出入。_

**状态：** accepted

## 背景
Agent 需要在本地快速访问近期记忆，同时需要持久化完整记忆到云端供回溯和多实例共享。

## 决策驱动
- 本地访问速度
- 云端持久化
- 多实例共享
- 内存占用控制

## 备选方案
- **分层存储（本地即时记忆 + 云端远期记忆）** — 优点：本地快速访问、云端持久化共享、支持记忆淘汰策略
- **纯本地存储** _（已否决）_ — 优点：实现简单、无网络开销；缺点：无法多实例共享、重启丢失、内存受限
- **纯云端存储** _（已否决）_ — 优点：天然共享、持久化；缺点：每次访问都有网络延迟、离线不可用

## 决策
本地维护 InstantMemory（近期记忆，ACTIVE→CONDENSED→EVICTED 状态流转），云端存储 Memory（远期记忆，压缩后的完整记忆），通过 cnaa_ref 引用关联两者。任务点完成时压缩完整记忆上传云端，本地仅保留摘要。

## 影响
本地内存占用可控，支持离线快速检索；云端提供完整记忆回溯和多实例共享能力；记忆沉淀规则（近期→远期）由 lifecycle 层统一管理。
