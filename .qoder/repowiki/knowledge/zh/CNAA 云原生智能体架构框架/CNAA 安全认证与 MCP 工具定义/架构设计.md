本模块由两个职责清晰的子文件组成：
- `security.py`：纯函数式安全层，通过 `AuthConfig`（dataclass）和 `AuthContext`（dataclass）表达配置与认证上下文，提供 `validate_api_key`、`check_permission`、`load_auth_config_from_env` 三个核心函数；权限模型采用 `PermissionLevel` 枚举（read_only / read_write / admin），认证默认关闭以保证向后兼容，API Key 查找使用 O(1) 字典。
- `tools.py`：MCP 工具声明中心，仅包含工具名常量、`get_tool_definitions()`/`get_tool_names()`/`get_tool_by_name()` 三个注册函数以及 `TOOL_PERMISSION_MAP` 权限映射表；所有输入 Schema 统一从 `cnaa.schemas` 导入，不重复定义。
依赖方向单向：`tools.py` → `cnaa.schemas`，`security.py` 不依赖其他 cnaa 子模块，两者均只使用 Python 标准库。
