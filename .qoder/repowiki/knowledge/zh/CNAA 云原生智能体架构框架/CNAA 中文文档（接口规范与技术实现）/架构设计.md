本模块为纯文档目录，包含两份 Markdown 文件：`api-reference-v0.1.md` 是面向外部使用者的接口契约文档，定义了 Memory、State、Preference、Environment、InstantMemory 等核心数据模型的 JSON Schema、13 个 MCP 工具的请求/响应格式、生命周期规则与安全认证机制；`technical-implementation.md` 是面向开发者的实现指南，按三层架构组织——核心契约层 `cnaa/`（models/schemas/interaction/lifecycle/security/tools）、云端实现层 `cloud/`（MCP Server + InMemory 存储后端）、本地实现层 `local/`（MCP Client + 即时记忆管理），并通过 ASCII 架构图和调用链路图说明 Agent 与 CNAA Server 之间的 MCP over HTTP 交互流程。两份文档互为补充：一份规定「做什么」，一份说明「怎么做」。
