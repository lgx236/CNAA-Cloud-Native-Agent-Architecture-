- 所有 JSON 接口字段采用 snake_case 命名，时间戳统一使用 ISO-8601 字符串格式
- 数据模型通过 Python dataclass 定义并在 `__post_init__` 中自动填充默认值（如 timestamp、updated_at）
- 抽象接口使用 ABC 基类定义（MemoryInterface、StateInterface），具体实现以 InMemory*Store 形式提供
- MCP 工具名称统一以 `cnaa_` 前缀命名（如 cnaa_store_memory、cnaa_get_state），并通过 TOOL_PERMISSION_MAP 映射读写权限
- 安全认证通过环境变量配置且默认关闭，保持向后兼容，API Key 绑定 agent_id 实现租户隔离
