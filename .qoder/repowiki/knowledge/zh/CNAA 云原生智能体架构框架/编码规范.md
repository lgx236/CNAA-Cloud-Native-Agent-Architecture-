- 所有 MCP 工具在 `cnaa/tools.py` 中统一注册，通过 `handle_tool_call` 按名称分发执行。
- 请求认证通过 `Authorization: Bearer <api_key>` 头传递，由 `cnaa.security.validate_api_key` 校验后以 `_auth_context` 注入参数。
- Schema 定义集中在 `cnaa/schemas.py`，对外通过 `get_all_schemas()` 暴露，工具调用前进行参数校验。
- 日志统一使用 Python `logging` 模块，HTTP 模式下覆盖 `log_message`，stdio 模式下输出至 stderr。
- 错误响应遵循 `{"status": "error", "message": "..."}` 或 JSON-RPC 2.0 标准 error 结构。
