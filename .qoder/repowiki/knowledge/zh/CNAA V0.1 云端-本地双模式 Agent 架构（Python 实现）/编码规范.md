- 所有模块使用 `from __future__ import annotations` 启用 PEP 563 延迟求值，避免循环导入。
- HTTP 响应统一通过 `_send_json` / `_send_error` 封装，错误体固定包含 `status` 与 `message` 字段。
- 数据存储通过抽象类（如 storage/state_store.py）定义接口，memory_store.py 与 state_store.py 分别实现内存与持久化变体。
- MCP 工具调用遵循 `{tool: str, arguments: dict}` JSON 请求格式，服务端统一在 handle_mcp 中解析并转发。
- 日志统一通过 logging.getLogger(__name__) 获取命名 logger，并按 `asctime - name - level - message` 格式输出。
- 类型注解全面使用 typing 模块（Any、dict[str, Any] 等），配合 mypy strict 模式进行静态检查。
