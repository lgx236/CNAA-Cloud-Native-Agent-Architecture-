测试套件按被测模块分层组织：`test_models.py` 验证 `cnaa.models` 中的数据类与枚举；`test_cloud_storage.py` 针对 `cloud.storage` 中的 `InMemoryMemoryStore` 和 `InMemoryStateStore` 进行 CRUD 与过滤测试；`test_local.py` 覆盖 `local.memory.instant_memory.InstantMemoryManager` 的状态机（ACTIVE→CONDENSED→EVICTED）及 `local.state.state_cache.StateCache` 的 TTL 缓存逻辑；`test_integration.py` 通过 `CNAA_MCPServer`、`CloudAgentInterface`、`LocalAgentInterface` 串联云-本地双模式，模拟完整任务到长期记忆的流转；`test_openclaw_integration.py` 使用 `unittest.mock.patch` 模拟 HTTP 请求验证 `examples.openclaw_integration.OpenClawCNAAIntegration` 的远程调用。所有测试均继承自 `unittest.TestCase`，通过 `setUp` 构造独立 fixture，测试之间互不依赖。
