- 每个测试类在 `setUp` 中构造被测对象并注入固定 `agent_id="test-agent"` 作为测试标识，确保用例间隔离。
- 断言统一使用 `self.assertEqual`、`self.assertIsNotNone`、`self.assertTrue/False` 等 unittest 内置方法，错误场景通过 `status` 字段断言（如 `"ok"`、`"not_found"`、`"error"`）。
- 测试方法命名采用 `test_<功能名>` 形式，并在 docstring 中以 `IMPLEMENTED:` 前缀标注实现状态。
- 对外部 HTTP 依赖（如 OpenClaw 集成）统一通过 `@patch("examples.openclaw_integration.requests.post")` 装饰器模拟，避免真实网络请求。
- 数据构造遵循「最小必要字段」原则，仅传入测试所需参数，其余字段依赖默认值（如 `tags=[]`、`completion_score=0.0`、`timestamp` 自动填充）。
