本模块为单一 Python 脚本 + 说明文档，充当 OpenClaw（TypeScript 智能体框架）与 CNAA 云端之间的轻量 HTTP 客户端。
- `openclaw_integration.py` 定义 `OpenClawCNAAIntegration` 类，通过统一的 `_call_mcp_tool(tool_name, arguments)` 方法向 `{cnaa_url}/mcp` 端点发起 POST 请求，以 JSON 格式传递 MCP 工具名与参数。
- 所有业务操作（记忆 store/get/list、状态 get/update、偏好 get/update、环境 get/update）均封装为独立方法，按功能分组注释（Memory/State/Preference/Environment Operations），形成清晰的 API 边界。
- 依赖方向单向：示例 → HTTP 客户端 → CNAA 云端服务器，不持有本地状态，体现 "Dumb Service" 设计原则。
- `README.md` 提供架构图、运行步骤与扩展计划，作为该集成的唯一入口文档。
