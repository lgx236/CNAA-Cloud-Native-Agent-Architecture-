### CNAA
- 定义：Cloud Native Agentic Architecture，一个面向 AI Agent 的持久化经验记忆运行时框架。核心价值是让经验（Experience）从 Prompt 的附属品变成独立的可管理资源，使任何 Agent 在无需修改推理逻辑的情况下实现经验沉淀、状态同步与持续记忆。
- 别名：Cloud Native Agentic Architecture

### Experience Runtime
- 定义：CNAA 的核心运行时组件，位于 AI Agent 和持久化记忆之间，提供 State Interface、Memory Manager、Task Lifecycle、Agent Adapter 等模块，负责协调任务执行过程中的经验收集、存储和恢复。
- 别名：经验运行时

### Persistent Experience Memory
- 定义：CNAA 提出的核心概念，指将任务经验作为独立于 Prompt 的持久化资源进行管理和复用，区别于传统的仅延长 context window 的记忆方案。
- 别名：持久化经验记忆

### CNAA State Service
- 定义：CNAA 的后端服务，通过 MCP/HTTP 协议为 Experience Runtime SDK 提供状态存储服务，是持久化记忆的实际存储层。
- 别名：状态服务

### 任务点分块
- 定义：CNAA 架构中的核心设计模式，将一个完整任务分解为多个任务点（checkpoint），每个任务点包含完整状态快照和轻量级即时记忆摘要，通过小索引指向大存储的模式模拟记忆的伪连续性。
- 别名：checkpoint、任务检查点

### 即时记忆
- 定义：保存在 Agent 本地的轻量级任务摘要，包含任务ID、完成度评分、时间戳和指向 CNAA 中完整细节的引用指针，用于实现跨 session 的记忆伪连续性。
- 别名：instant memory、轻量记忆

### 伪连续性
- 定义：通过即时记忆（轻量摘要）+ 云端细节回溯（完整快照）的组合模式，在不追求真正连续记忆的前提下，模拟出类似人类记忆的连续性体验。
- 别名：pseudo-continuity

### FullSnapshot
- 定义：任务点的完整状态快照，包含详细的执行记录、工具调用历史等重量级数据，存储在 CNAA 后端，通过即时记忆中的 cnaa_ref 引用访问。
- 别名：完整快照
