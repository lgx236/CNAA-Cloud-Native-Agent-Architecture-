## 🔧 Implementation Details

### Plugin Architecture Design

```python
# Base interface
class BaseScorer(ABC):
    @abstractmethod
    def score(self, memory: Any) -> float:
        pass

# Factory pattern for loading algorithms
def load_algorithm(name: str, config: dict | None = None) -> BaseScorer:
    if name == "simple_recency":
        return SimpleRecencyScorer(config)
    elif name == "composite_v1":
        return CompositeV1Scorer(config)
    else:
        raise ValueError(...)
```

**Key Benefits:**
- 🔄 Algorithm swappable without code changes
- 🎯 Zero impact on existing interfaces
- 🚀 Easy to add new algorithms as plugins
- 📝 Well-documented extension points

### Storage Interface Extension

```python
class MemoryInterface(ABC):
    def get_memory_scores(
        self,
        agent_id: str,
        access_counts: dict | None = None,
        context: dict | None = None,
    ) -> list[dict]:
        """Calculate composite scores using configured algorithm."""
        pass
```

This allows storage layer to delegate scoring to algorithm plugins while maintaining clean separation of concerns.

## 🎯 Key Design Decisions

### Why SQLite Instead of PostgreSQL?

1. **Zero Setup**: No separate database process needed
2. **Single File**: Easy backup (`cp cnaa.db backup.db`)
3. **Python Native**: No extra dependencies
4. **ACID Safe**: Production-ready transactions
5. **Scalability**: Good for ≤1M records per agent

**Future Enhancement**: Can be swapped for PostgreSQL via configuration.

### Why Simple Algorithms?

1. **Explainable**: Easy to understand and debug
2. **Fast**: Microsecond-scale computation
3. **Configurable**: Weights adjustable via params
4. **Swap-able**: Plugins allow runtime changes

**Trade-off**: Less sophisticated than ML-based approaches
**Benefit**: Predictable behavior, easy to maintain

### Why Plugin Architecture?

1. **Separation of Concerns**: Storage vs Computation
2. **Easy Extension**: Drop-in new algorithms
3. **No Breaking Changes**: Existing code untouched
4. **Testing Isolation**: Each algorithm independently testable
